# Knowledge base sources

All documents used by IncidentPilot's knowledge base come from public sources.

They are not stored in this repository. run the scripts in `app/rag/` to download them.

| Category | Source | License (verify at the source) |
|---|---|---|
| database | PostgreSQL documentation, postgresql.org/docs | PostgreSQL License |
| deployment, network | Kubernetes documentation, kubernetes.io/docs | CC BY 4.0 |
| security | OWASP Cheat Sheet Series, cheatsheetseries.owasp.org | CC BY-SA 4.0 |
